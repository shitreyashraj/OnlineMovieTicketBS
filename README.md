# Yashraj CineFlex 🎬

### Online Movie Ticket Booking System

Yashraj CineFlex is a web-based movie ticket booking application built with PHP and MySQL. It is designed to let users browse movies, explore showtimes, and book movie tickets online. The project also includes administration features for managing movies, theatres, and shows.

## Features

- User registration and login
- Browse movies and showtimes
- Movie ticket booking
- Theatre and show management
- Admin dashboard
- Database-driven application

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Version Control:** Git and GitHub
- **CI/CD:** GitHub Actions workflow
- **Cloud:** Microsoft Azure App Service (deployment to be verified)

## Run Locally

1. Install XAMPP or another PHP/MySQL development environment.
2. Clone or download this repository.
3. Place the application in your local web server directory.
4. Create a MySQL database and import the project's SQL file, if provided.
5. Configure the database connection using your local settings.
6. Start Apache and MySQL, then open the application in your browser.
